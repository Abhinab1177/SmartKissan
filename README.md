## 📖 About

SmartKissan is an AI-powered smart farming platform developed to assist farmers in monitoring crop health, detecting plant diseases, managing irrigation, and making informed farming decisions.

The project combines Artificial Intelligence, Machine Learning, Computer Vision, IoT, and weather data to provide an easy-to-use dashboard for smart agriculture. It consists of both a software platform and a Raspberry Pi-based hardware prototype.

## 🖥️ Project Modules

### 🌿 Disease Detection
Upload crop leaf images and detect diseases using an AI model. The system provides disease prediction along with treatment recommendations.

### 📊 Dashboard
Monitor farm activities through a modern dashboard featuring weather information, analytics, disease history, and smart farming insights.

### 🌦️ Weather Monitoring
Displays live weather conditions and provides farming recommendations based on environmental data.

### 💧 Smart Irrigation
The Raspberry Pi hardware prototype controls irrigation using relay modules and a water pump for efficient water management.

### 🏪 Dukan
Locate nearby agricultural stores including seed shops, fertilizer stores, pesticide shops, and nurseries.

### 🤖 Kissan Sahayak AI
An AI-powered chatbot that assists farmers by answering agriculture-related questions and providing farming guidance.
