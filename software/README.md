# Software

The software module of SmartKissan provides a web-based dashboard for crop disease detection and smart irrigation management.

## Features

- Crop disease detection using deep learning
- Plant image upload
- Disease prediction
- Smart irrigation control
- Weather information
- Dashboard for monitoring

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- TensorFlow
- OpenWeather API

## Folder Structure

```text
software/
├── frontend/
└── ml-model/
```

The frontend and machine learning modules are organized separately for easier development and maintenance.
