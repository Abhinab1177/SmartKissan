# Wiring Guide

This project uses a Raspberry Pi Zero 2W to control a bulb and a fan through a relay module.

## Connections

| Raspberry Pi Pin | Connected To |
|------------------|--------------|
| GPIO 23 | Relay IN1 (Fan) |
| GPIO 24 | Relay IN2 (Bulb) |
| 5V | Relay VCC |
| GND | Relay GND |

## Components

- Raspberry Pi Zero 2W
- Pi Camera Module
- 2-Channel Relay Module
- Breadboard
- Jumper Wires
- LED Bulb
- DC Motor (Fan)
