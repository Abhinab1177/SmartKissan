# SmartKissan Installation Guide

This guide explains how to run the SmartKissan project locally.

## Requirements

- Python 3.10 or above
- Git
- Modern Web Browser
- Raspberry Pi (for hardware prototype)

## Clone the Repository

```bash
git clone https://github.com/Abhinab1177/SmartKissan.git
cd SmartKissan
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```

## Hardware Requirements

- Raspberry Pi 4
- Raspberry Pi Camera
- 4-Channel Relay Module
- 5V DC Water Pump
- Power Supply

## Notes

This repository contains both the software implementation and the hardware prototype. Some hardware features require a Raspberry Pi and compatible peripherals.
